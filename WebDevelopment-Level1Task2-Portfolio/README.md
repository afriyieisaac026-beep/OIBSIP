# Alex Morgan Personal Portfolio

A responsive personal portfolio website for a fictional frontend developer. It presents a short professional profile, technical skills, selected project concepts, and contact links in a clean editorial layout.

## Features

- Hero/profile section with name, role, intro, and professional avatar placeholder
- About Me section with background and interests
- Visual skills grid
- Two project cards with descriptions and GitHub placeholder links
- Contact section with email, LinkedIn, GitHub, and Behance links
- Smooth scrolling navigation
- Responsive desktop and mobile layout

## Tech Stack

- HTML5
- CSS3
- Google Fonts
- Unsplash image URL for the avatar placeholder

## Run Locally

Open `index.html` directly in a browser. No build step or JavaScript is required.
