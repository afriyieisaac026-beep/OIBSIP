# Luna Pizza

A visually polished static landing page for a fictional wood-fired pizza brand. The design uses a warm editorial palette, expressive typography, food photography, and responsive CSS layout.

## Features

- Sticky navigation with three links
- Hero section with headline, supporting copy, and calls to action
- Responsive craft/feature grid
- Brand story section with supporting image
- Testimonial and booking CTA
- Footer with placeholder email, Instagram, and newsletter links
- Responsive layout for desktop and mobile widths

## Tech Stack

- HTML5
- CSS3
- Google Fonts
- Unsplash image URLs

## Run Locally

Open `index.html` directly in a browser. No build step or JavaScript is required.

## Project Structure

- `index.html` - semantic page structure and content
- `style.css` - responsive layout, typography, colors, and component styling
