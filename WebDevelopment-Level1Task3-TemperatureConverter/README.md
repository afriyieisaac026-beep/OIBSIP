# Thermo Temperature Converter

A responsive temperature conversion tool built with vanilla HTML, CSS, and JavaScript. It converts between Celsius, Fahrenheit, and Kelvin and displays every output scale at once.

## Features

- Numeric temperature input with validation
- Celsius, Fahrenheit, and Kelvin input unit selector
- Convert button with real-time result display
- Friendly errors for invalid values and absolute-zero violations
- Responsive centered interface for desktop and mobile
- Accessible labels, live status messages, and keyboard-friendly controls

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Run Locally

Open `index.html` directly in a browser. No build step or dependencies are required.
